# 👑 N-Rainhas: O Desafio Real para Android
Bem-vindo ao **N-Rainhas**, um jogo de quebra-cabeça desafiador e elegante para Android, baseado no clássico problema matemático das Oito Rainhas. Este projeto transforma um famoso exercício de lógica em uma experiência de jogo divertida e minimalista, perfeita para treinar seu cérebro e passar o tempo.

##♟️ O que é o Problema das N-Rainhas?
O objetivo é simples, mas a solução é complexa: posicione N rainhas em um tabuleiro de xadrez NxN de forma que nenhuma rainha possa atacar a outra. Isso significa que não pode haver duas rainhas na mesma:

* **Linha**
* **Coluna**
* **Diagonal**

Você tem o que é preciso para governar o tabuleiro?

## ✨ Funcionalidades
Nosso jogo traz o desafio clássico para a ponta dos seus dedos com uma interface limpa e funcionalidades intuitivas:

* Dificuldade Ajustável: Escolha o tamanho do seu desafio! Jogue em tabuleiros que vão de 4x4 (4 rainhas) até 8x8 (8 rainhas).

* Design Elegante: Uma interface com tema de xadrez, bonita e focada na jogabilidade.

* Controle de Som: Ative ou desative a música para uma experiência de jogo personalizada.

* Recordes e Cronômetro: Desafie-se a resolver o quebra-cabeça o mais rápido possível e tente bater seus próprios recordes!

## 🕹️ Como Jogar

** O arquivo de Apk está na pasta "Apk" no diretório principal, basta baixar o arquivo e instalar o app *
  
1. Configure o Jogo: Na tela inicial, vá em Configurar Jogo para escolher o número de rainhas (de 4 a 8) e ajustar a opção de som.

2. Inicie a Partida: Volte ao menu e clique em Jogar.

3. Posicione as Rainhas: Toque em um quadrado do tabuleiro para posicionar uma rainha.

4. Pense Estrategicamente: Coloque todas as rainhas no tabuleiro seguindo as regras. Se você cometer um erro (uma rainha atacar a outra), a casa ficará marcada, indicando um conflito. Clicar novamente na casa remove a rainha em conflito.

5. Vença o Desafio: O jogo termina quando você conseguir posicionar todas as N rainhas corretamente no tabuleiro. O seu tempo será registrado!

6. Recomece: Se ficar preso, use o botão Reiniciar para limpar o tabuleiro e tentar uma nova estratégia.
